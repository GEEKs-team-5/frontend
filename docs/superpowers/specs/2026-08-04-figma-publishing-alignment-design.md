# Figma 퍼블리싱 정합화 설계

## 목표

`GEEKs` Figma 페이지(393 × 852 모바일 화면)를 기준으로 현재 구현에서 눈에 띄는 퍼블리싱 차이만 수정한다.

## 범위

- 보호자 경로에서 하단 내비게이션의 링크와 활성 상태를 보호자 화면에 맞춘다.
- 약 등록·수정 폼에서 CTA와 겹치는 임시 DUR 텍스트 버튼을 제거한다.
- 보호자 일간 리포트 카드를 Figma의 높이, 우측 화살표, 여백에 맞춘다.
- 복용자 월간 리포트 차트의 높이를 Figma와 같은 344px로 맞춘다.
- 회원가입 단계가 바뀔 때 페이지 스크롤을 맨 위로 되돌린다.

## 제외 범위

- DUR 검색·병용금기 확인의 실제 사용자 흐름 구현
- OCR, 알림, 월간 집계 API, 역할 전환
- 디자인 시스템 추출과 FSD 리팩터링

## 검증

- 변경한 화면의 393 × 852 브라우저 캡처를 Figma와 대조한다.
- 관련 정적 테스트, FSD 검사, ESLint, 포맷 검사를 실행한다.
