# 회원가입 화면 퍼블리싱 설계

## 범위

- 현재 인증 진입 화면에 회원가입 UI 플로우를 추가한다.
- 흐름은 이메일, 비밀번호 확인, 사용자 유형, 보호자 또는 복용자 후속 단계다.
- Figma의 `인증 코드` 표기는 화면과 접근성 문구에서 모두 `초대 코드`로 쓴다.
- 회원가입 API, 완료 화면, 서버에서 생성하는 실제 초대 코드는 구현하지 않는다.

## 흐름

1. 시작 또는 로그인 화면의 회원가입을 누르면 이메일 입력으로 이동한다.
2. 이메일 다음에는 비밀번호와 비밀번호 확인을 입력한다.
3. 사용자 유형에서 보호자 또는 복용자를 선택한다.
4. 보호자는 고정 초대 코드 `123268`을 보고 복사할 수 있다.
5. 복용자는 나이와 성별을 입력한 뒤 초대 코드를 입력한다.
6. 각 단계의 뒤로 가기는 직전 화면으로 이동한다.

## 구현

- 기존 `AuthEntryView`가 전체 화면 상태와 입력값을 관리한다.
- 이메일·비밀번호·나이는 네이티브 input을, 사용자 유형·성별은 네이티브 select를 쓴다.
- 각 단계는 필수값이 있을 때만 다음 단계로 이동한다.
- 초대 코드 복사는 브라우저 Clipboard API가 지원될 때만 수행하며, 지원하지 않으면 화면 상태는 유지한다.

## 검증

- 이메일부터 보호자·복용자 분기까지 전환을 단위 테스트로 확인한다.
- 393px 모바일 뷰포트에서 Figma와 대조한다.
- `pnpm lint:fsd`, `pnpm lint`, `pnpm format:check`, `pnpm build`를 실행한다.
