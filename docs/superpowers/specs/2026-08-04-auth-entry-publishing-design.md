# 인증 진입 화면 퍼블리싱 설계

## 범위

- Figma의 스플래시, 시작, 로그인 화면을 모바일 PWA 기준으로 구현한다.
- 회원가입 화면과 로그인·회원가입 API 연동은 구현하지 않는다.
- iOS 상태 바, 홈 인디케이터, 키보드는 기기 목업이므로 구현하지 않는다.

## 흐름

1. 스플래시를 1초간 표시한 뒤 시작 화면으로 전환한다.
2. 시작 화면의 로그인 버튼은 로그인 화면으로 전환한다.
3. 로그인 화면의 뒤로 가기는 시작 화면으로 전환한다.
4. 회원가입 버튼과 로그인 제출은 API가 준비될 때까지 화면상 동작을 추가하지 않는다.

## 구현

- 인증 진입 흐름은 하나의 클라이언트 뷰가 화면 상태를 관리한다.
- Figma의 MediLink 로고 에셋을 내려받아 정적 파일로 사용한다.
- 반복되는 버튼과 입력은 해당 뷰 내부에서만 재사용한다. 공용 UI 라이브러리는 만들지 않는다.
- 이메일·비밀번호 입력은 각각 `email`, `password` 타입의 네이티브 input을 사용하고, 비밀번호 표시 전환을 제공한다.

## 검증

- 스플래시에서 시작 화면으로 자동 전환되는지 확인한다.
- 로그인 진입, 뒤로 가기, 비밀번호 표시 전환을 확인한다.
- `pnpm lint:fsd`, `pnpm lint`, `pnpm format:check`, `pnpm build`를 실행한다.
